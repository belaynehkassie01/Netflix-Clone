# Netflix Clone

A Netflix-inspired web application built with React that allows users to browse movies and TV shows through a modern streaming-platform interface.

## Features

- Netflix-style homepage
- Responsive design
- Movie and TV show listings
- Dynamic content rendering
- Modern UI components
- API integration

## Technologies Used

- React.js
- JavaScript
- CSS
- Axios
- TMDB API

```bash

cd netflix-clone
npm install
npm start
```
